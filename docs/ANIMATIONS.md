# Scroll and animation behaviour

This documents every motion pattern in the storefront so it can be reproduced, tuned or tested. Implementation lives in `frontend/src/hooks/`, `frontend/src/components/` and `frontend/src/index.css`.

## Timing tokens

| Token | Value | Used for |
|---|---|---|
| `--transition-1` | `0.25s ease` | colour changes, underline, back-to-top |
| `--transition-2` | `0.5s ease` | sticky header, card actions, image zoom, shine |
| `--transition-3` | `1s ease` | scroll reveal |
| `--cubic-in` / `--cubic-out` | `cubic-bezier(.51,.03,.64,.28)` / `(.33,.85,.4,.96)` | mobile drawer close / open |

## 1. Sticky header (hide on scroll down, show on scroll up)

Hook: `useHeaderScroll`. State is derived on every scroll event:

- `active` when `scrollY > 150`: the bar becomes `position: fixed; top: -80px` with `translateY(100%)` and a shadow, so it slides down into view (0.5s).
- `hidden` when the current scroll position is greater than the previous one (scrolling down): `translateY(0)` pulls it back up out of view and removes the shadow. Scrolling up (or staying still) shows it again.
- **Below 1200px** the whole top bar (menu, logo, actions) is the sticky element. **At 1200px and up** only the navigation row is sticky, and the top bar scrolls away normally.

## 2. Scroll reveal

Hook: `useScrollReveal` + `<Section>`. Every `<section data-section>` has its direct children start at `translateY(100px); opacity: 0`. When the section's top edge crosses the middle of the viewport (`top < innerHeight / 2`), the class `active` is added and the children transition to `translateY(0); opacity: 1` over 1s. It runs on load, on every scroll, and when a section mounts (so content that arrives after an API call still reveals). The class is never removed, so sections reveal once.

## 3. Back to top

Appears (fade + rises 10px) once `scrollY > 150`; click scrolls smoothly to the top. `html { scroll-behavior: smooth }`.

## 4. Shine hover (hero, collection tiles, offer banner)

Class `hover-shine`. On hover the background image scales to 1.15 (0.5s) and a skewed translucent highlight sweeps left to right (`@keyframes shine`, 1s).

## 5. Product card actions

Add-to-bag and view buttons sit at the right edge of the image, hidden. On hover or keyboard focus within the card they fade in and slide 20px left (0.5s).

## 6. Navigation

- Desktop links get an underline that grows from the left (`scaleX(0 -> 1)`, 0.25s).
- Mobile drawer slides in from the left: 0.4s `cubic-out` opening, 0.25s `cubic-in` closing, with a 50% black overlay. Escape or a click on the overlay closes it.

## Accessibility

`prefers-reduced-motion: reduce` disables reveal, header slide, card action slide, zoom and shine, and turns off smooth scrolling.
